# Hi, I'm Ash 👋

**Senior Data Engineer · NLP/ML Researcher · Bay Area, CA**

I build large-scale data systems by day and research neural machine translation for low-resource languages by night. Recently published **CRAFT** — a clustered-regression approach to adaptive training-data filtering for NMT — at **DATA 2026**.

---

### 🔬 What I'm working on

- 🧠 **Research:** Data selection for low-resource NMT (EN→HI) — clustering + conditional regression over 33M-pair corpora, fine-tuning mBART-50 with LoRA
- 📄 **Latest paper:** [CRAFT: Clustered Regression for Adaptive Filtering of Training Data](https://arxiv.org/abs/2604.22693) — DATA 2026 (SCITEPRESS)
- 🛠️ **Engineering:** 10+ years building data pipelines and platforms at scale (Clarivate, Unilever, Wipro, and more)
- 🎓 Currently a Research Assistant in Software Localization @ BITS Pilani Hyderabad
