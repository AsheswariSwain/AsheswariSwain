# Hi, I'm Asheswari 👋

**ML Platform Engineer · NLP/ML Researcher · San Jose, CA**

I've spent 10+ years designing scalable distributed systems, data pipelines, and end-to-end ML infrastructure — from data ingestion to model deployment and monitoring. These days I also research neural machine translation for low-resource languages, and recently co-authored **CRAFT**, a data filtering framework for sequence-to-sequence fine-tuning, published at **DATA 2026**.

---

### 🔬 What I'm working on

- 📄 **Latest paper:** [CRAFT: Clustered Regression for Adaptive Filtering of Training Data](https://arxiv.org/abs/2604.22693) — DATA 2026 (SCITEPRESS), with collaborators at Google and BITS Pilani
- 🧠 **Research:** Data selection for NMT (EN→HI, EN→ES) — k-means clustering + conditional regression with KL-divergence guarantees, fine-tuning mBART with LoRA over corpora like WikiMatrix and IIT Bombay EN–HI
- 🎓 AI Research Assistant, LLM-based Software Localization @ BITS Pilani (with Dr. S. Panda)
- 🛠️ **Previously:** Staff/Senior Data & AI engineering at Celebal Technology, Clarivate Analytics, Unilever, and Wipro — petabyte-scale platforms, streaming pipelines, MLOps, and cloud migrations
